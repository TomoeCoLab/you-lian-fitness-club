# 動作教學維護規範

修改或新增動作必須遵循 `../docs/exercise-content-workflow.md`，並閱讀適用的 fitness-movement-infographic skill。

1. 每動作 JSON 是唯一可編輯教學來源；網站與 Markdown 由它生成。
2. 先查原始來源並鎖定版本、器材、左右側計數；一般健康頁不能核准特定動作。
3. 文字、圖、影片分開記錄狀態與證據；能播放、提示詞正確、沒有明顯錯誤都不是專業認證。
4. 內容或圖像變更後必須重新審查；不可批次自動刷新 hash 假裝完成審查。
5. 產圖先完成明確分鏡；使用者核准成年角色、繁體中文、無標語、自然視線。生成後仍須查看實際圖片。
6. 有錯誤、不一致或尚未檢視的圖片不展示；錯配影片不播放。保留舊資產作追蹤，不直接刪除。
7. 審查不足就寫明不足；不要使用「全部正確」「已認證」等超出證據的說法。
8. `npm run content:build`、`npm test`、建置及桌面／手機瀏覽器測試均須通過。
