# 動作教學：文字先行的維護流程

## 單一來源

每個動作只有一份 `content/exercises/<id>.json`。網站與 [文字總冊](exercise-content.md) 都從它生成。文字主檔能降低重複辨圖成本，但不能證明新生成圖片正確；每個新成品仍需視覺檢查。

資料包含：指定版本、完整起始與回程、提示、計數方式、呼吸、停止條件、預設份量性質、來源支持範圍、文字／圖／影片各自審查、圖像 SHA-256、生成所用文字 hash 與分鏡。課表的份量可以覆寫動作預設，不應把圖上的組數當作所有課表都適用。

## 新增／修訂順序

1. **定義動作**：確認地面／上斜／跪姿、單側／雙側、啞鈴數量、器械型號。機台未確定前，不編造滾墊、軸心、解鎖與上下機方式。
2. **核對來源**：優先原廠、醫療機構或健身教育機構的該動作原始教學。記 URL、日期、支持哪些要點、不支持哪些內容。搜尋摘要與片名只能當候選線索。
3. **寫文字**：步驟包括起始、主要動作、回程／退出；明示每側或合計、一組是否單側、計時是否含休息。一般起始份量不是個人處方。疼痛、麻木、頭暈等不適需停止，不以「加墊／減幅」取代疼痛警示。
4. **審文字與分鏡**：來源核對與內部一致性分開；來源不足維持 `pending`。分鏡逐格寫視角、肢體、支撐點、頭頸、回程、標題與短句。靜態動作不可假造往返。器材需可追溯到實際機型。
5. **產圖**：讀取既有 `fitness-movement-infographic` skill，附核准成年角色參考。`npm run content:prompt -- bird-dog` 只輸出已核對文字且分鏡 ready 的提示詞，不能自動核准圖片。無成功標語、繁體中文、自然視線。記錄真正使用的內容 hash、參考圖、提示詞、產圖工具與日期；歷史圖片來源不明須保持 `null`，不可補填目前 hash。
6. **驗圖**：查看實際原圖所有格，對照文字及來源。檢查肢體對側、支撐點、器材接合、箭頭、回程、文字、份量與視線。問題圖用 `needs-revision` 或 `blocked`，保留原因，重製通過才設 `visual-checked`；這仍不是專業動作認證。
7. **驗影片**：先核對來源頻道與確切版本，再實際看設定、動作、回程、換側及安全提示，記時間範圍和觀察。舊資料只有數個截點，因此叫 `spot-checked`，不能宣稱完整觀看。單膝／雙膝、不同起始姿勢不可當完全同版。來源變更、區段變更或內容改動都需重驗。
8. **驗網站**：`npm run content:build`、`npm test`、`npm run build`、`npm run test:browser`；手機與桌面實際確認圖、文字、影片狀態、影片禁用及課表份量。文字／圖示待核對狀態不得被其他入口繞過。

## 審查 hash 規則

- `contentHash` 包含教學、定義、來源、分鏡；改任何一項，舊文字／圖片核對會成 `stale`。
- `illustration.sha256` 必須與原圖檔一致；不一致直接阻擋建置。重新產圖需更新資產 hash 並重新驗圖，不能只更新 hash 解除警報。
- `review.image.reviewedImageSha256` 是實際檢查過的圖片；`generatedFromContentHash` 是產圖時真正使用的文字，兩者不同用途。
- `review.video.auditBaselineContentHash` 是該次影片抽查所對照內容的變更偵測基準，本身不是播放證據；實際時間點與觀察另記在 `check`。未來內容／URL 改動會使片段抽查失效。變更配對時把原影片與檢查結果留在 `review.video.history`，不要覆蓋掉停用原因。
- 不提供自動 approve 指令。核對人須完成相應檢查後，才手動更新狀態、日期及 hash。建置只驗資料，不會自動提升狀態。
- 目前影片 schema 只有片段抽查，不允許把 `fullPlaybackReviewed` 設成 true。日後完整審片需先擴充證據欄位（涵蓋區段、設定／動作／回程等），不能直接換布林值冒充。

## 本次修復結果與限制（2026-09-20）

76 筆文字紀錄（75 個可選動作與 1 個歷史別名）均已對照動作專屬來源；76 筆目前圖解均已人工檢視可見內容。共重製 35 張不同圖解，舊過頭伸展別名共用修正後圖片；保留舊圖、已記錄的拒收試作與採用成品真正產圖時使用的提示詞／hash，不事後補造歷史來源。已修正機型、滾墊／支撐位置、對側肢體、起始回程、單側計數與圖文份量矛盾。沒有以更新 hash 取代實際驗圖。

影片 56 筆為實際播放器畫面片段抽查；本輪另重新播放核對 41 筆，包括已失效的核對與替換配對。死蟲式換為 90/90 起始、門框伸展換為雙側、仰躺扭轉換為雙膝；蝴蝶機換為握把式、腿推換為 45 度斜板、過頭伸展換為站姿；肩推亦更換為能實際核對的版本。調整骨盆前後傾、史密斯深蹲等播放邊界，避免接入其他動作。不同機型的調節不可互套，影片節奏／份量不覆蓋本站課表。可見畫面抽查不能宣稱完整審片、醫療審查或專業動作認證。

原先列出的 20 項待補影片仍獨立列為待核對，原連結不可播放或另開；不以不相符示範填空。它們是：高腳杯深蹲、啞鈴彎舉、彈力帶俯身划船、滑輪三頭下壓、啞鈴側平舉、啞鈴弓箭步、輔助引體向上、臀推機臀推、哈克深蹲、站姿提踵、坐姿大腿內收、反向蝴蝶機、反向弓箭步、登山者、靠牆深蹲停留、俯臥超人式、跪姿髖屈肌伸展、下犬式、低眼鏡蛇式、坐姿腿後側伸展。之後補片仍須先對照指定版本、實際播放、記錄時間點，再開放；不可僅根據片名或頻道知名度核准。

全部文字主檔及已完成分鏡可作為未來核對基準，但歷史未重製圖仍沒有可追溯的產圖提示詞；其 `generatedFromContentHash` 維持 null，分鏡草稿也不冒充已核准。新增或再次重製必須把分鏡提升為 ready 才能輸出正式產圖提示詞。文字可以減少反覆辨圖，不能免除新成品驗圖。

最新狀態以自動生成的 [總冊](exercise-content.md) 及各 JSON 為準。後續補片與完整逐段影片審查是尚未完成的工作，不包含在「圖文修復完成」的宣稱中。2026-09-20 經使用者核准，已將完成內容納入 v1.8.0 部署；20 項待補影片留待後續，維持停用。發布前通過 28 項資料／邏輯測試與 13 項瀏覽器測試，部署後再驗證版本、75 張預覽資產及桌面／手機訪客流程。
