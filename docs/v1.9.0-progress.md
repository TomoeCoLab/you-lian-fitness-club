## 內容與圖解

- 53 項先確定器材與動作版本、中文教學、重點、份量、左右計數及分鏡，再以 fitness-movement-infographic / imagegen 產圖。
- 逐張查看實際輸出；錯誤方向、字幕及器械連線曾退回重製。退回原圖移至 `content/image-history/v1.9.0/`，保留原因與 SHA-256，不公開部署。
- 既有 21 張圖與文字重新對照新影片；史密斯深蹲改用平地版本，不使用墊高腳跟的片段。
- 高位單臂滑輪反向飛鳥、髖高單臂滑輪側平舉、掌心向下的反握／腕彎舉等版本分開定義。
- 混合動作 Shorts 以 start/end 指定區段；不宣稱全片觀看、醫療審查或專業動作認證。
- generation hash 保留實際生成依據；後續繁體字修正只更新經重新比對的內容核對 hash，不竄改原生成版本。
- 前台只保留實用教學、安全提醒與原始影片／來源，不放內部核對狀態或檢查紀錄。
- 新增 5 種器材分類及簡圖；補充自重、單顆啞鈴、曲槓總重與地雷管加片重量記法。
