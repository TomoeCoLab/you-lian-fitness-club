# 自訂動作永久識別碼與正式收錄

自訂動作 ID 是公開引用契約，已被個人課表、訓練草稿、打卡快照與 AI JSON 使用。不能因改名、共用或正式收錄而重新發號。

## 本版共用

- 登入者經既有伺服器驗證後，讀取同一 custom_exercises 池。原資料列、建立者與所有 ID 均保留；不搬移或重寫既有課表與歷史。
- 新增時先按 NFKC 名稱、部位、tracking 尋找既有項目。同組資料重用原 ID；新的項目用此三欄的雜湊產生穩定 ID，並由主鍵避免同時建立重複項。
- 休息秒數及逐組份量保存在各課表／訓練快照，可各自調整；共用池不會覆寫訓練。
- 訪客池仍限本機；不公開成員的動作或建立者資料到公開 AI 目錄。

## 日後正式收錄的必要步驟

1. 先讀取原自訂動作 ID。正式動作文字主檔的 id 必須沿用此 ID（即使是 UUID 或 custom- 前綴），不可改成新的英文 slug。
2. 按既有內容流程補教學、來源、影片與圖解。不得改變同一 ID 的原本動作或 tracking 語意；不同變式建立不同動作。
3. 保留 custom_exercises 原資料列。前端自訂池會排除已存在於正式目錄的同 ID 項目，避免顯示兩次；官方目錄與 AI 匯入優先採正式資料。
4. 舊課表仍引用相同 ID，組數／重量／時間快照不變；今日課表及訓練畫面以 ID 查到正式指引。打卡歷史保留原名稱與當時數據，不重寫。
5. 若有多個歷史重複 ID，先保留各自 ID，不能刪列或用名稱猜測合併。需要合併時，另外建立可追蹤別名映射並驗證所有讀取入口後才執行。

新增官方動作時須以此流程檢查既有自訂池，避免另造 ID 導致關聯中斷。
